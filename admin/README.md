# Months エディター（試験用）

作業ブランチ work/responsive-unification だけに記事を保存する設定です。
公開サイト（main）には反映しません。

- 「日付」は当日が初期値ですが、自由に変更できます。
- 「タイトル」は日本語・英語どちらでも使えます。
- 新しいファイル名は「指定日付-タイトル.md」で自動生成する設定です。
- URL（permalink）は従来どおり自分で入力します。
- layout は default に固定して新規作成します。
- 画像は images フォルダーにアップロードする設定です。
- 既存記事はテスト中に保存し直さないでください。
- Jekyll本来の表示を確認するには、別途作業ブランチのプレビューデプロイが必要です。

公開前に「日本語ファイル名・日付変更・画像挿入・URL」の動作確認が必要です。
