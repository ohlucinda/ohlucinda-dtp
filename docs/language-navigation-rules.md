# OHLUCINDA 言語・HOME遷移ルール

この文書は OHLUCINDA サイトの継続的な制作・修正時に守る仕様です。

## 最優先原則
閲覧者が選んだ表示言語を、ページ遷移やHOMEへの帰還によって勝手に変更しない。
日本語から移動した人は日本語へ、英語から移動した人は英語へ戻る。明示的な言語切り替えは常に優先する。

## HOME
- 日本語: https://ohlucinda.com/ （明示的に指定する場合は `?lang=ja`）
- 英語: https://ohlucinda.com/?lang=en
- `lang=en` / `lang=ja` の明示指定がある場合は必ずそれを優先する。
- HOME の表示言語をユーザーが選んだ場合は、現在の仕組み `ohlucinda-home-language` に正しく保存する。
- クエリがなくても保存済みの言語を尊重する。リファラーだけを唯一の判定材料にしない。
- 言語別の内部リンク、作品への導線、HOME復帰リンクが選択言語を適切に引き継ぐこと。

## 各ページのHOMEリンク
- 固定の `https://ohlucinda.com/` によって英語表示を失わせない。
- HOMEへ戻る先を決める際は、ページ側で選択された言語、遷移元の明示的な言語指定、保存済みのHOME言語など、ページごとの実装に応じた信頼できる情報を用いる。
- 英語復帰は `https://ohlucinda.com/?lang=en`、日本語復帰は `https://ohlucinda.com/?lang=ja` を明示できる。
- 別の作品サイトの「HOME」は、そのサイト内トップを意味する場合がある。**総合HOMEと作品サイトHOMEを混同しない。** Lyrics や About Je'm など、入口に応じた戻り先の既存仕様は維持する。
- `work_lang` など作品表示用の言語指定と、総合HOME用 `lang` の違いに注意する。

## 制作・変更時の禁止事項
- レイアウト変更、文章差し替え、画像変更のついでに言語設定を初期化しない。
- HOMEを旧プレビューHTMLで丸ごと上書きしない。必ず**最新の公開ソース**から最小限の差分を反映する。
- 既存の保存処理、クエリ引き継ぎ、復帰先処理を検査せずに削除・置換しない。
- 見た目、余白、フォントなどはユーザーから変更指示がない限り維持する。

## 公開前チェック（必須）
- 日本語HOME → Anything Goes → HOME → 日本語
- 英語HOME → Anything Goes → HOME → 英語
- 日本語HOME → About / Bookmarks / Months → HOME → 日本語
- 英語HOME → About / Bookmarks / Months → HOME → 英語
- Lyrics / About Je'm の既存の入口別HOME動作が壊れていない
- 最新作品リンクなど、HOMEの見出し以外から入る経路も確認する
- 日本語→英語、英語→日本語へ明示的に切り替えた後の復帰先を確認する
- PC・スマートフォンそれぞれで確認する
