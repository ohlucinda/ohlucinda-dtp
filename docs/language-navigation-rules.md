# OHLUCINDA 言語・HOME遷移ルール

この文書は OHLUCINDA サイトの継続的な制作・修正時に守る仕様です。

## 最優先原則
閲覧者が選んだ表示言語を、ページ遷移やHOMEへの帰還によって勝手に変更しない。
日本語から移動した人は日本語へ、英語から移動した人は英語へ戻る。明示的な言語切り替えは常に優先する。

## HOME
- 日本語: https://ohlucinda.com/ （明示的に指定する場合は `?lang=ja`）
- 英語: https://ohlucinda.com/?lang=en
- `lang=en` / `lang=ja` の明示指定がある場合は必ずそれを優先する。
- HOME の表示言語をユーザーが選んだ場合は、現在の仕組み `ohlucinda-home-language` に正しく保存する。
- クエリがなくても保存済みの言語を尊重する。リファラーだけを唯一の判定材料にしない。
- 言語別の内部リンク、作品への導線、HOME復帰リンクが選択言語を適切に引き継ぐこと。

## 各ページのHOMEリンク
- 固定の `https://ohlucinda.com/` によって英語表示を失わせない。
- HOMEへ戻る先を決める際は、ページ側で選択された言語、遷移元の明示的な言語指定、保存済みのHOME言語など、ページごとの実装に応じた信頼できる情報を用いる。
- 英語復帰は `https://ohlucinda.com/?lang=en`、日本語復帰は `https://ohlucinda.com/?lang=ja` を明示できる。
- 別の作品サイトの「HOME」は、そのサイト内トップを意味する場合がある。**総合HOMEと作品サイトHOMEを混同しない。** Lyrics や About Je'm など、入口に応じた戻り先の既存仕様は維持する。
- `work_lang` など作品表示用の言語指定と、総合HOME用 `lang` の違いに注意する。

## 制作・変更時の禁止事項
- レイアウト変更、文章差し替え、画像変更のついでに言語設定を初期化しない。
- HOMEを旧プレビューHTMLで丸ごと上書きしない。必ず**最新の公開ソース**から最小限の差分を反映する。
- 既存の保存処理、クエリ引き継ぎ、復帰先処理を検査せずに削除・置換しない。
- 見た目、余白、フォントなどはユーザーから変更指示がない限り維持する。

## 公開前チェック（必須）
- 日本語HOME → Anything Goes → HOME → 日本語
- 英語HOME → Anything Goes → HOME → 英語
- 日本語HOME → About / Bookmarks / Months → HOME → 日本語
- 英語HOME → About / Bookmarks / Months → HOME → 英語
- Lyrics / About Je'm の既存の入口別HOME動作が壊れていない
- 最新作品リンクなど、HOMEの見出し以外から入る経路も確認する
- 日本語→英語、英語→日本語へ明示的に切り替えた後の復帰先を確認する
- PC・スマートフォンそれぞれで確認する


## ナビゲーションの位置・書式（変更禁止・固定仕様）

この仕様は、何度も調整して確定したものであり、制作中の別の作業に付随して変更してはならない。

- **OHLUCINDA総合HOMEを基準**とし、各ページ右上の日本語 / English / HOME を、現在揃えた位置・高さに維持する。
- About と Bookmarks のナビゲーションを既存の整列基準とする。Anything Goes と寄り道（日本語・英語）は、この基準に揃えた現在の設定を維持する。
- ナビゲーションの**縦位置・横位置・右端・文字サイズ・フォント・文字間隔・項目間隔・下線・表示順序・レスポンシブ動作**を、他の修正のついでに変更してはならない。
- ナビゲーション位置のために、本文、見出し、作品表示、ページ全体の余白を移動させない。
- CSSを整理・共通化する際にも、既存の優先順位や最終的な表示を変更しない。特に `.site-navigation-header` と `.top.site-navigation-header`、関連するメディアクエリは慎重に扱う。
- **ユーザー本人が明確にナビゲーション変更を指示した場合のみ**、現在の公開ソースを確認し、対象箇所だけを変更する。意図しない影響がないか比較・確認する。
- 公開前には、HOME・About・Bookmarks・Anything Goes・寄り道の日本語版と英語版を同じ画面幅で比較し、右上ナビゲーションが揃っているか確認する。PC幅と狭い画面の両方で検査する。
- 実ブラウザで未確認なら「確認済み」と報告しない。

**このルールを変更する場合も、ユーザーの明示的な指示が必要。**

## 適用範囲の確定（一覧・個別作品も含む）

- OHLUCINDAの総合サイトに属する**すべてのページと表示状態**に、上記ナビゲーションの固定仕様を適用する。
- HOME、About、Bookmarks、Months、Anything Goes、寄り道だけでなく、**Anything Goes内の個別作品ページ・作品表示ビューアー**、寄り道の個別記事、および今後新しく追加する総合サイト内ページも対象とする。
- 一覧から作品を開いたときや、作品内で言語を切り替えたときにも、ナビゲーションの高さ・右端位置・フォント・文字サイズ・各リンクの間隔・表示順・下線・画面幅ごとの挙動はHOME基準で揃える。画面の種類に応じて必要な操作が異なる場合も、共通部分の見え方を維持する。
- **Lyrics、Je'mなどの独立した作品サイトは対象外**。独立サイト固有のナビゲーションやデザインを統一目的で変更しない。
- 新規ページの制作時は、この基準を最初から使う。既存の完成済みページを別作業のついでに変更しない。
- 現在の全ページの一致が実機で検証済みという意味ではない。今後の変更時に対象画面を比較・検証する。

## 検証と報告
GitHubの変更成功と、実際の公開サイトのブラウザ動作確認は別物。
テストが実行できていないときは「未確認」と明記し、動作を保証しない。
この文書は仕様と手動確認項目を定めるもの。自動テストの実装や全ページ検証を完了したことは意味しない。
